    🔑 Gemini 연결 설정 · 사용 방법
    1. Google AI Studio(aistudio.google.com)에 접속해 구글 계정으로 로그인합니다.
    2. 화면의 "API 키 받기"(Get API key) 메뉴에서 새 키를 만들고 복사합니다. (메뉴 이름은 바뀔 수 있어요)
    3. 아래 API 키 칸에 붙여넣고 연결 테스트를 누릅니다. "연결됨"이 나오면 끝입니다. 키는 이 컴퓨터(브라우저)에만 저장됩니다.
    4. 학생을 고르고 관찰 메모를 적은 뒤 ✨ AI로 바로 작성을 누르면 초안이 아래에 나옵니다. 마음에 들면 위 입력칸에 넣기로 옮겨 다듬습니다.
    • 무료 사용량에는 한도가 있어서, 한도를 넘으면 잠시 뒤에 다시 시도해야 할 수 있습니다. 요금·한도 정책은 구글이 바꿀 수 있으니 AI Studio 안내를 확인하세요.
    • 모델 이름은 구글이 새 모델을 내면 바뀝니다. "모델을 찾을 수 없다"는 오류가 나오면 AI Studio에서 쓸 수 있는 모델 이름으로 바꿔 입력하세요.
    • 개인정보: 보낸 내용은 구글 서버로 전송됩니다. 학생 이름·학번은 기본으로 "학생"으로 바꿔 보내지만, 메모 속 다른 개인정보(전화번호, 가정 사정 등)는 그대로 가니 필요한 내용만 적으세요. 학교나 교육청의 AI 사용 지침이 있다면 따라 주세요.
    • 키는 비밀번호처럼 다루세요. 다른 사람에게 알려주거나 메신저·메일로 보내지 마세요. 공유용 프로그램은 선생님마다 각자 자기 키를 만들어 입력해야 합니다.
    • AI가 쓴 글은 초안입니다. 사실과 다른 내용이 없는지, 학교의 생활기록부 기재요령에 맞는지 꼭 확인한 뒤 사용하세요.

    AI 결과는 초안입니다. 사실과 다른 내용이 없는지, 학교의 생활기록부 기재요령에 맞는지 꼭 확인해 주세요. 이름을 빼도 메모 속 다른 개인정보는 그대로 전달되니 필요한 내용만 적으세요.
